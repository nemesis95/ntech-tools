# Changelog

## 0.0.1 — Initial release

- Added cross-platform server launchers for Windows, macOS, and Linux.
- Added browser-based file and folder upload.
- Added preservation of nested folder structures.
- Added per-file progress, receiver acknowledgements, and error reporting.
- Added simultaneous sender support.
- Added collision-safe file naming and path validation.
- Added transfer event logging and interrupted-upload cleanup.
- Added complete English project documentation and tutorial.
