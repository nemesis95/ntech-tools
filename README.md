# PS3 catalog update workspace

## Branch purpose

`catalog-add-ps3-legacy-browser-bridge` was used to prepare the PS3 Legacy Browser Bridge entry for the NTech Tools catalog.

This is not a tool release or an active development branch. The complete and current list of tools is maintained on `main`; PS3 Legacy Browser Bridge development continues on `ps3-legacy-browser-bridge-dev`, and its stable release is available on `ps3-legacy-browser-bridge-v0.1.0`.
